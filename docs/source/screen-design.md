## 4. 공통 화면 규칙

| 항목 | 규칙 |
|---|---|
| 인증 필요 화면 | `SC-04` 이후 주요 서비스 화면은 인증 필요로 본다. |
| 비인증 접근 | 인증 필요 화면 접근 시 로그인 화면으로 이동한다. |
| 성공 메시지 | 생성/수정/삭제 성공 시 사용자에게 처리 결과를 표시한다. |
| 실패 메시지 | API 오류의 공통 에러 응답 형식은 `api-spec.md`에서 TBD다. 화면 설계에서는 오류 원인별 메시지 영역을 둔다. |
| 날짜/시간 입력 | 일정 화면은 시작 일시와 종료 일시를 입력한다. 종료 일시는 시작 일시보다 빠를 수 없다. |
| 권한 노출 | 수정/삭제 버튼은 가능한 경우 본인 또는 권한 있는 사용자에게만 노출한다. |

## 5. 화면 상세

### SC-01. 로그인

| 항목 | 내용 |
|---|---|
| 화면 목적 | 회원이 아이디와 비밀번호로 서비스를 시작하는 진입 화면 |
| 진입 경로 | 사이트 진입, 로그아웃 후 이동 |
| 주요 구성 | 아이디 입력, 비밀번호 입력, 로그인 버튼, 회원가입 링크, 아이디 찾기 링크, 비밀번호 찾기 링크 |
| 입력 필드 | `login_id`, `password` |
| 버튼/액션 | 로그인, 회원가입 이동, 아이디 찾기 이동, 비밀번호 찾기 이동 |
| 연동 API | `POST /api/auth/login` |
| 성공 처리 | 로그인 성공 시 메인 페이지 또는 학습자료 목록 화면으로 이동 |
| 검증/예외 | 필수값 누락, 로그인 실패, 탈퇴 계정 접근 |
| 관련 요구사항 | 1-2 |
| 관련 유저 플로우 | UF-01, UF-02, UF-03 |

### SC-05. 학습자료 상세 / 피드백

| 항목 | 내용 |
|---|---|
| 화면 목적 | 게시글 내용, 첨부파일, 댓글을 확인하고 피드백을 작성 |
