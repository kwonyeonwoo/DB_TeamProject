## 4. 공통 화면 규칙

| 항목 | 규칙 |
|---|---|
| 인증 필요 화면 | `SC-06` 이후 주요 서비스 화면은 인증 필요로 본다. |
| 비인증 접근 | 인증 필요 화면 접근 시 로그인 화면으로 이동한다. |
| 로그아웃 | 로그아웃 시 서버에 저장된 사용자 세션을 무효화하고 로그인 화면으로 이동한다. |
| 성공 메시지 | 생성/수정/삭제 성공 시 사용자에게 처리 결과를 표시한다. |
| 실패 메시지 | API 오류는 공통 에러 응답의 `message`를 기본으로 표시한다. 입력값별 상세 오류가 필요한 경우 선택값 `details`를 함께 사용할 수 있다. |
| 날짜/시간 입력 | 일정 화면은 날짜, 시작 시간, 종료 시간, 일정 종류, 일정 제목, 메모를 입력한다. 종료 일시는 시작 일시보다 빠를 수 없다. |
| 일정 종류 | 일정 종류는 `1`: 수업, `2`: 과제, `3`: 시험, `4`: 스터디, `5`: 기타 중 하나다. |
| 권한 노출 | 게시글/댓글/대댓글 수정·삭제는 작성자에게만, 그룹 일정 수정·삭제는 해당 그룹원에게만, 관리자 신고 관리는 ADMIN에게만 노출한다. |
| 작성자 표시 | 익명 작성물은 `익명_숫자`, 탈퇴 회원 작성물은 `탈퇴한 유저`로 표시한다. 탈퇴 회원 표시가 익명 표시보다 우선한다. |
| 익명 번호 기준 | `익명_숫자`는 하나의 게시글 상세 화면 기준으로 부여하며, 같은 게시글 안의 동일 작성자는 항상 같은 번호로 표시한다. |
| 탈퇴 작성물 노출 | 탈퇴 회원의 게시글, 댓글, 대댓글은 삭제하지 않으며 조회, 검색, 페이지네이션 대상에 포함한다. |
| 탈퇴 시 삭제 데이터 | 탈퇴 회원의 개인 캘린더, 개인 일정, 유일 그룹원 그룹은 즉시 삭제한다. |
| 신고 | 일반 사용자는 게시글 또는 댓글을 신고할 수 있고, 관리자는 신고 목록을 조회, 처리할 수 있다. 신고 처리는 신고 상태만 변경하며 게시글/댓글 삭제를 자동 수행하지 않는다. 신고 대상 게시글 또는 댓글이 삭제된 경우 관리자 신고 목록에서는 해당 대상을 `삭제된 대상`으로 표시한다. |
| 그룹 채팅 | 그룹 채팅은 구현하지 않으므로 진입점, 탭, 버튼, API 호출을 제공하지 않는다. |

## 5. 화면 상세

### SC-01. 로그인

| 항목 | 내용 |
|---|---|
| 화면 목적 | 회원이 아이디와 비밀번호로 서비스를 시작하는 진입 화면 |
| 진입 경로 | 로그아웃 상태의 사이트 진입, 로그아웃 후 이동, 회원 탈퇴 완료 후 이동 |
| 주요 구성 | 아이디 입력, 비밀번호 입력, 로그인 버튼, 회원가입 링크 |
| 입력 필드 | `login_id`, `password` |
| 버튼/액션 | 로그인, 회원가입 이동 |
| 연동 API | `POST /api/auth/login` |
| 성공 처리 | 로그인 성공 시 메인 페이지로 이동 |
| 검증/예외 | 필수값 누락, 로그인 실패, 탈퇴 계정 접근 |
| 관련 요구사항 | 1-2, 1-4 |
| 관련 유저 플로우 | UF-01, UF-03 |

### SC-02. 회원가입

| 항목 | 내용 |
|---|---|
| 화면 목적 | 신규 회원 정보를 등록하고 로그인 가능한 계정을 생성 |
| 진입 경로 | 로그인 화면의 회원가입 링크 |
| 주요 구성 | 이름, 아이디, 비밀번호, 이메일 입력, 가입 버튼 |
| 입력 필드 | `name`, `login_id`, `password`, `email_address` |
| 버튼/액션 | 가입하기, 취소 또는 로그인 화면 이동 |
| 연동 API | `POST /api/auth/signup` |
| 성공 처리 | 가입 완료 후 로그인 화면으로 이동 |
| 검증/예외 | 필수값 누락, 아이디 중복, 이메일 중복. 탈퇴 회원의 NULL 처리된 아이디/이메일은 중복 판단 대상에서 제외 |
| 관련 요구사항 | 1-1 |
| 관련 유저 플로우 | UF-02 |

### SC-06. 메인

| 항목 | 내용 |
|---|---|
| 화면 목적 | 로그인한 사용자가 주요 서비스 기능으로 이동하는 시작 화면 |
| 진입 경로 | 로그인 성공, 인증 상태 확인 성공 |
| 주요 구성 | 게시판 진입, 알림 버튼, 마이페이지 진입, 개인 캘린더 진입, 로그아웃 버튼 |
| 입력 필드 | 없음 |
| 버튼/액션 | 게시판 이동, 알림 팝업 열기, 마이페이지 이동, 개인 캘린더 이동, 로그아웃 |
| 연동 API | 로그아웃: `POST /api/auth/logout`; 알림 목록은 `SC-07`에서 호출 |
| 성공 처리 | 선택한 화면으로 이동. 로그아웃 시 세션 무효화 후 로그인 화면으로 이동 |
| 검증/예외 | 인증 만료 시 로그인 화면 이동 |

| 관련 유저 플로우 | UF-01, UF-03, UF-07 |

### SC-07. 알림 목록 팝업

| 항목 | 내용 |
|---|---|
| 화면 목적 | 로그인한 회원이 자신에게 온 알림을 팝업 형태로 조회하고 대상 위치로 이동 |
| 진입 경로 | 메인 화면의 알림 버튼 |
| 주요 구성 | 알림 목록, 알림 내용, 읽음 상태, 생성 일시, 닫기 버튼 |
| 입력 필드 | 없음 |
| 버튼/액션 | 알림 팝업 열기, 알림 항목 클릭, 닫기 |
| 연동 API | `GET /api/notifications` |
| 성공 처리 | 본인 알림 목록을 표시하고, 목록 조회 시 조회된 알림을 읽음 처리한다. 댓글 알림 클릭 시 게시글 상세로 이동하고, 대댓글 알림 클릭 시 부모 댓글 위치로 이동한다. |
| 검증/예외 | 알림 없음, 다른 회원 알림 접근 차단, 대상 게시글 또는 댓글 없음 |
| 데이터 표시 | 댓글 알림은 `commented_post_id`를 대상 게시글로 사용하고 `commented_id`는 NULL이다. 대댓글 알림은 `commented_post_id`와 부모 댓글 id인 `commented_id`를 함께 사용한다. |
| 관련 요구사항 | 2-1, 2-2, 2-3 |
| 관련 유저 플로우 | UF-07 |

### SC-08. 게시판 목록 / 검색

| 항목 | 내용 |
|---|---|
| 화면 목적 | 게시글을 최신순 목록으로 조회하고 단일 필터로 검색 |
| 진입 경로 | 메인 화면의 게시판 버튼 |
| 주요 구성 | 검색어 입력, 작성자 필터, 주제 필터, 게시글 목록, 페이지 번호, 글쓰기 버튼 |
| 입력 필드 | `page`, `keyword`, `author`, 주제 필터(`main_category`, `sub_category`) |
| 버튼/액션 | 검색, 필터 적용, 페이지 이동, 게시글 선택, 글쓰기 이동 |
| 연동 API | `GET /api/posts` |
| 성공 처리 | 작성일 기준 최신순으로 조건에 맞는 게시글 목록 표시 |
| 목록 표시 | 제목, 작성자 표시명, 작성 일자, 조회수, 대주제, 소주제, 추천 수, 수정 여부를 표시한다. 익명 작성자는 `익명_숫자`, 탈퇴 작성자는 `탈퇴한 유저`로 표시한다. |
| 검증/예외 | 검색 결과 없음, 페이지 범위 초과, 비로그인 접근, 검색어/작성자/주제 필터 중 둘 이상의 필터 동시 사용 |
| 필터 규칙 | 주제 필터의 대주제/소주제는 하나의 주제 필터 묶음으로 취급한다. 작성자 필터 결과에서는 탈퇴한 유저의 게시글과 익명 유저의 게시글을 제외한다. |
| 관련 요구사항 | 3-3, 4-5, 4-6 |
| 관련 유저 플로우 | UF-08, UF-14 |

### SC-09. 게시글 상세 / 피드백

| 항목 | 내용 |
|---|---|
| 화면 목적 | 게시글 내용, 첨부파일, 댓글/대댓글을 확인하고 추천 또는 피드백 작성 |
| 진입 경로 | 게시판 목록에서 게시글 선택, 알림 클릭 후 대상 게시글 또는 부모 댓글 위치 이동 |
| 주요 구성 | 제목, 작성자 표시명, 작성 일자, 수정 여부, 조회수, 대주제/소주제, 본문, 첨부파일, 추천 버튼, 수정/삭제 버튼, 댓글 목록, 댓글/대댓글 작성 영역 |
| 입력 필드 | 댓글 작성: `content`, `is_anonymous`; 대댓글 작성: `content`, `is_anonymous` |
| 버튼/액션 | 추천 등록/취소, 게시글 신고, 댓글 신고, 댓글 작성, 대댓글 작성, 게시글 수정, 게시글 삭제, 댓글 수정, 댓글 삭제, 대댓글 수정, 대댓글 삭제 |
| 연동 API | `GET /api/posts/{post_id}`, `POST/DELETE /api/posts/{post_id}/likes`, `POST /api/reports`, `GET/POST /api/posts/{post_id}/comments`, `POST /api/comments/{comment_id}/replies`, `PATCH/DELETE /api/comments/{comment_id}`, `DELETE /api/posts/{post_id}` |
| 성공 처리 | 게시글 상세 접근 시 조회수를 증가시킨다. 추천 버튼 클릭 시 등록/취소 상태와 버튼 색상을 토글한다. 댓글 작성자가 게시글 작성자와 다른 회원이면 게시글 작성자에게 댓글 알림을 생성하고, 대댓글 작성자가 부모 댓글 작성자와 다른 회원이면 부모 댓글 작성자에게 대댓글 알림을 생성한다. 댓글/대댓글 수정 또는 삭제 후 전체 화면을 갱신한다. 게시글 삭제 성공 시 게시판 첫 번째 페이지로 이동한다. |
| 작성자 표시 | 익명 게시글/댓글/대댓글은 `익명_숫자`로 표시한다. 탈퇴 회원 작성물은 익명 여부보다 `탈퇴한 유저` 표시를 우선한다. |
| 권한 노출 | 게시글 수정/삭제는 게시글 작성자에게만 노출한다. 댓글/대댓글 수정/삭제는 해당 댓글/대댓글 작성자에게만 노출한다. |
| 신고 처리 | 신고 사유는 1: 부적절한 내용, 2: 광고/도배, 3: 저작권 침해, 4: 기타 중 하나를 선택한다. 동일 회원은 동일 신고 대상에 대해 한 번만 신고할 수 있다. |

| 게시글 목록 | 페이지 범위 초과, 검색 결과 없음, 검색어/작성자/주제 필터 동시 사용 불가, 작성자 필터에서 탈퇴/익명 작성자 제외 |
| 게시글 작성/수정 | 대주제/소주제/제목 필수, 작성자만 수정/삭제, 직접 파일 업로드 실패, 익명 여부 유지, 새 파일 업로드 시 첨부파일 전체 교체 |
| 게시글 상세 | 상세 접근 시 조회수 증가, 게시글 없음, 권한 없음, 삭제 후 게시판 첫 번째 페이지 이동 |
| 추천 | 게시글당 회원 1회 추천 유지, 재클릭 시 추천 취소와 버튼 색상 원복 |
| 신고 | 게시글 또는 댓글 신고, 신고 사유 유형 필수, 동일 회원의 동일 대상 중복 신고 불가, 관리자만 신고 목록 조회/처리, 신고 처리 시 신고 상태만 변경, 삭제된 신고 대상은 관리자 신고 목록에서 `삭제된 대상`으로 표시 |
| 댓글 | 내용 필수, 작성자만 수정/삭제, 익명 여부 선택, 수정/삭제 후 전체 화면 갱신 |
| 대댓글 | 일반 댓글에만 대댓글 작성 가능, 대댓글에는 다시 대댓글 작성 불가, 작성자만 수정/삭제 |
| 작성자 표시 | 익명 작성자는 `익명_숫자`, 탈퇴 작성자는 `탈퇴한 유저`; 탈퇴 작성자 표시가 우선 |
| 개인 일정 | 본인 일정만 조회/수정/삭제, 종료 일시가 시작 일시보다 빠른 경우 |
| 그룹 | 그룹원만 그룹 상세/일정 접근, 이미 가입한 그룹, 유효하지 않은 그룹 가입 코드, 현재 그룹장 `leader_id`/LEADER 자동 등록 |
| 그룹 일정 | 그룹원 전체 조회/등록/수정/삭제 가능, 타 그룹 일정 접근 차단, 일정 저장 필수값 |
| 그룹 채팅 | 구현 제외이므로 화면 진입점과 API를 제공하지 않음 |
