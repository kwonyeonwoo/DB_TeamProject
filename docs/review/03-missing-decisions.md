# 03. Missing Decisions

검증일: 2026-05-12

범위: 수정된 `docs/source/requirements.md` 기준 구현 전 사용자 결정이 필요한 항목 확인

구현 가능 여부: **PASS**

## 1. 현재 구현 전 결정 필요 사항

| ID | Severity | Related document | Problem | Why it matters | Suggested fix | Required user decision |
|---|---|---|---|---|---|---|
| 없음 | - | - | 현재 구현 전 반드시 결정해야 할 미결정 사항 없음 | - | - | 없음 |

## 2. 해결된 결정 사항

| 이전 ID | 이전 Severity | 현재 상태 | 반영 내용 |
|---|---|---|---|
| D-Q01 | QUESTION | 해결 | 신고 생성은 일반 사용자(USER)만 가능하다. 관리자(ADMIN)는 `POST /api/reports` 신고 생성 API를 호출할 수 없다. 이 결정은 `requirements.md`, `api-spec.md`, 정규화 문서의 USER 전용 권한 정책과 일치한다. |

## 3. 새 결정이 필요하지 않은 것으로 확인한 항목

| 항목 | 현재 상태 |
|---|---|
| 공통 에러 응답 | `code`, `message` 필수, `details` 선택으로 확정되어 있다. |
| 회원 역할 | `USER`, `ADMIN`; 가입 기본값 USER; ADMIN 부여 API 제외로 확정되어 있다. |
| 신고 생성 권한 | 일반 사용자(USER)만 가능하고 관리자(ADMIN)는 호출할 수 없는 것으로 확정되어 있다. |
| 회원 탈퇴 처리 | 회원 row 유지, `status = DELETED`, `deleted_at`, 6개월 후 개인정보 NULL 처리, 작성물 유지로 확정되어 있다. |
| 탈퇴 작성자 표시 | 익명보다 `탈퇴한 유저` 표시가 우선으로 확정되어 있다. |
| 개인 일정 탈퇴 처리 | 탈퇴 시 개인 캘린더/개인 일정 즉시 삭제로 확정되어 있다. |
| 그룹장 탈퇴 처리 | 가장 먼저 가입한 다른 그룹원에게 자동 위임, 유일 그룹원이면 그룹 즉시 삭제로 확정되어 있다. |
| 파일 업로드 | 직접 업로드, `/uploads/posts/{post_id}/{UUID}`, DB에는 `file_url`만 저장, 파일 메타데이터 미저장으로 확정되어 있다. |
| 파일 제한 정책 | 파일 크기와 확장자 제한은 최소 구현 범위에서 별도 요구사항으로 두지 않는 것으로 확정되어 있다. |
| 신고 사유 | `1`: 부적절한 내용, `2`: 광고/도배, `3`: 저작권 침해, `4`: 기타로 확정되어 있다. |
| 신고 처리 상태 | `PENDING`, `PROCESSED`로 확정되어 있다. |
| 신고 처리 결과 | `report.status`, `processed_by`, `processed_at`만 저장하는 것으로 확정되어 있다. |
| 신고 대상 삭제 후 이력 | 신고 이력 유지, 관리자 목록 `삭제된 대상` 표시로 확정되어 있다. |
| 일정 종류 | `1`: 수업, `2`: 과제, `3`: 시험, `4`: 스터디, `5`: 기타로 확정되어 있다. |
| 그룹 가입 UX | `group_code` 단순 입력 방식이며 `group_link`는 같은 값으로 확정되어 있다. |
| 그룹 채팅 | 구현 제외로 확정되어 있다. |

## 4. 정규화 문서 영향

현재 `docs/normalized` 문서들은 신고 생성 USER 전용 정책을 이미 반영하고 있으므로 추가 수정이 필요하지 않다.

## 5. 구현 시작 판단

**PASS**

현재 source 문서 기준으로 구현 전 추가 사용자 결정이 필요한 항목은 없다. 정규화 명세와 구현 계획을 기준으로 다음 단계 진행이 가능하다.
