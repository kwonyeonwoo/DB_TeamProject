# 03. Missing Decisions

검증일: 2026-05-12

범위: 최신 `docs/source` 문서 재검증 및 구현 전 결정 필요 항목 확인

구현 가능 여부: **PASS**

최종 재확인: 2026-05-12 기준 구현 전 사용자 결정이 필요한 신규 미결정 사항은 추가로 발견되지 않았다.

## 1. 현재 구현 전 결정 필요 사항

| ID | Severity | Related document | Problem | Why it matters | Suggested fix | Required user decision |
|---|---|---|---|---|---|---|
| 없음 | - | - | 현재 구현 전 반드시 결정해야 할 미결정 사항 없음 | - | - | 없음 |

## 2. 이전 미결정 항목 해소 결과

| 이전 ID | 이전 Severity | 현재 상태 | 반영 내용 |
|---|---|---|---|
| D-01 | QUESTION | 해결 | 게시글 또는 댓글이 hard delete되어도 해당 대상을 가리키던 기존 `report` 이력은 유지한다. 관리자 신고 목록에서는 삭제된 신고 대상을 `삭제된 대상`으로 표시한다. |
| D-M01 | MAJOR | 해결 | ERD Mermaid의 `users -> groups` 관계 라벨을 `groups.leader_id = 현재 그룹장`으로 수정했다. |
| 공통 오류 응답 body 형식 | MAJOR | 해결 유지 | 실패 응답 body는 `code`, `message` 필수, `details` 선택으로 확정되어 있다. |
| 파일 업로드 저장 경로/DB 저장값 | MAJOR | 해결 유지 | 파일 저장 경로는 `/uploads/posts/{post_id}/{UUID}`, DB 저장값은 `file_url`로 확정되어 있다. |
| 관리자 권한 부여 방식 | QUESTION | 해결 유지 | 회원 가입/API로 ADMIN을 부여하지 않고 DB seed 또는 운영자 DB 변경으로만 부여한다. |
| 관리자 신고 처리 결과 저장 방식 | QUESTION | 해결 유지 | `report.status`, `processed_by`, `processed_at`만 변경 및 저장한다. |
| 그룹 가입 코드 UX | QUESTION | 해결 유지 | `group_code`를 화면에 표시하고 가입자는 코드를 입력한다. |
| 현재 그룹장 기준 | BLOCKER | 해결 | `groups.leader_id`를 현재 그룹장으로 사용한다. |
| 개인 일정 및 유일 그룹원 그룹 탈퇴 처리 | BLOCKER | 해결 | 탈퇴 시 개인 일정은 즉시 삭제하고, 탈퇴 회원이 유일한 그룹원인 그룹은 즉시 삭제한다. |

## 3. 구현 범위에서 제외 또는 확정된 항목

| 항목 | 현재 상태 |
|---|---|
| 아이디 찾기 | 구현 범위 제외 |
| 비밀번호 찾기 및 재설정 | 구현 범위 제외 |
| ADMIN 권한 부여 API | 구현 범위 제외 |
| 그룹 채팅 | 구현 범위 제외 |
| 복잡한 초대 링크/외부 공유/만료/재발급 | 구현 범위 제외 |
| 파일 메타데이터 저장 | 구현 범위 제외 |
| 공통 오류 응답 | `code`, `message`, 선택 `details`로 확정 |
| 신고 처리 상태 | `PENDING`, `PROCESSED`로 확정 |
| 신고 대상 삭제 후 표시 | `삭제된 대상`으로 확정 |
| 그룹 가입 UX | 그룹 생성자가 코드를 확인하고 가입자가 코드를 입력하는 방식으로 확정 |
| 현재 그룹장 저장 기준 | `groups.leader_id`로 확정 |
| 개인 일정 및 유일 그룹원 그룹 탈퇴 처리 | 즉시 삭제로 확정 |

## 4. 구현 시작 판단

**PASS**
