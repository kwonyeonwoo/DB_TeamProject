# Frontend Progress

이 문서는 `frontend/init` 브랜치에서 프론트엔드 구현 진행 상황을 기록한다.

## 기준

- 저장소: `kwonyeonwoo/DB_TeamProject`
- 브랜치: `frontend/init`
- 프론트엔드 경로: `frontend`
- 명세 기준: `docs/normalized` 및 `docs/source`의 요구사항, API, 화면 흐름 문서

## 완료된 단계

### 1단계: 프로젝트 실행/구조 안정화

- Vite 기본 예제 화면을 제거했다.
- React Router 기반 라우팅 구조를 구성했다.
- 공통 레이아웃과 상단 메뉴를 구성했다.
- 주요 화면의 임시 UI를 문서 기준 화면 흐름에 맞춰 배치했다.

### 2단계: 인증

- 서버 세션 기반 인증 흐름을 전제로 API 함수 구조를 만들었다.
- 공통 API 클라이언트에 `withCredentials: true`를 적용했다.
- 현재 사용자 조회, 로그인, 회원가입, 로그아웃, 내 정보 수정, 회원 탈퇴 함수 구조를 추가했다.
- `AuthProvider`로 사용자 상태를 관리한다.
- 비로그인 사용자, 로그인 사용자, 관리자 전용 라우트를 구분했다.
- 백엔드 미완성 상황을 고려해 `VITE_USE_MOCK_API=true`일 때만 동작하는 임시 mock 인증 흐름을 추가했다.

### 3단계: 게시글

- 게시글 목록, 상세, 작성, 수정, 삭제, 좋아요 API 함수 구조를 추가했다.
- 실제 백엔드 연결 전 화면 흐름 확인을 위해 mock 게시글 저장소를 추가했다.
- 게시글 목록 화면에서 검색어, 작성자, 분류 중 하나만 선택해 조회하도록 구성했다.
- 게시글 상세 화면에서 본문, 작성자 표시명, 조회수, 좋아요 수, 첨부 파일 목록을 표시한다.
- 게시글 작성 화면은 수정 화면으로도 재사용한다.
- 작성과 파일 업로드 요청은 `multipart/form-data` 기준으로 구성했다.

### 4단계: 댓글/알림

- 댓글 목록, 작성, 대댓글 작성, 수정, 삭제 API 함수 구조를 추가했다.
- 게시글 상세 화면 안에서 댓글과 대댓글을 표시한다.
- 댓글과 대댓글 작성 시 익명 여부를 선택할 수 있다.
- 알림 목록 API 함수 구조를 추가했다.
- 로그인 상태의 상단 메뉴에 알림 팝업을 추가했다.
- 알림을 클릭하면 게시글 상세 또는 댓글 앵커 위치로 이동한다.

### 5단계: 일정

- 개인 일정 목록, 생성, 수정, 삭제 API 함수 구조를 추가했다.
- 개인 일정 mock 저장소를 추가했다.
- 일정 화면에서 기간 필터로 겹치는 일정을 조회한다.
- 일정 등록과 수정은 모달 UI에서 처리한다.
- 일정 삭제 흐름을 연결했다.
- `type` 값은 문서 기준에 맞춰 1부터 5 사이 숫자로 유지한다.
- 종료 시간이 시작 시간보다 빠른 경우 저장하지 않도록 검증한다.

### 6단계: 그룹

- 그룹 목록, 생성, 코드 참여, 상세 조회 API 함수 구조를 추가했다.
- 그룹 멤버 목록을 그룹 상세 영역에서 표시한다.
- 그룹 일정 목록, 생성, 수정, 삭제 API 함수 구조를 추가했다.
- 그룹 화면에서 내 그룹 선택, 그룹 생성, 코드 참여를 처리한다.
- 선택한 그룹의 코드, 멤버, 그룹 일정을 한 화면에서 확인한다.
- 그룹 일정 등록과 수정은 모달 UI에서 처리한다.
- 그룹 일정 `type` 값은 문서 기준에 맞춰 1부터 5 사이 숫자로 유지한다.

### 7단계: 신고/관리자

- 일반 사용자용 신고 생성 API 함수 구조를 추가했다.
- 관리자용 신고 목록 조회와 처리 API 함수 구조를 추가했다.
- 게시글 상세 화면에서 게시글 신고와 댓글/대댓글 신고를 연결했다.
- ADMIN 계정은 일반 신고 생성 대상이 아니므로 신고 버튼이 보이지 않도록 분리했다.
- 관리자 신고 관리 화면에서 신고 목록, 사유, 대상, 처리 상태를 확인할 수 있다.
- 신고 처리 시 문서 기준에 따라 게시글이나 댓글을 자동 삭제하지 않고 신고 상태만 변경한다.
